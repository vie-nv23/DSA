# Bài tập tuần 13 - Cây nhị phân tìm kiếm

- Cài đặt cây nhị phân tìm kiếm ( BST ).
- Chèn các giá trị năm sinh vào cây.
- Duyệt cây theo thứ tự NLR.
- Tìm kiếm giá trị năm sinh 2004 trên cây.
- Độ phức tạp của thuật toán tìm kiếm.

## Dữ liệu sử dụng

( 2001, 2002, 2006, 2007, 2003, 2004, 2005, 2001, 1999, 2004 )

## Kết quả

Chương trình tạo được cây NP, duyệt cây theo thứ tự NLR và tìm kiếm được giá trị sinh viên năm sinh 2004.

## Độ phức tạp thuật toán tìm kiếm

- Trường hợp tốt nhất: O(1)
- Trường hợp trung bình: O(log n)
- Trường hợp xấu nhất: O(n)
